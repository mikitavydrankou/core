# Test client

Небольшой браузерный клиент для проверки websocket на backend.

## Как запустить

1. Поднимите backend, чтобы `ws://127.0.0.1:8000/ws` был доступен.
2. Из папки `test_client` запустите любой статический сервер, например:

```bash
python3 -m http.server 8081
```

3. Откройте `http://localhost:8081/index.html`.
4. Нажмите `Connect`. Если включен `Auto-send every 2-5 seconds`, клиент начнет сам отправлять JSON-сообщения.
5. Смотрите ответы в окне клиента и сообщения backend в его логах. Backend должен вернуть `Echo: ...`.

Если backend работает не на `127.0.0.1:8000`, поменяйте URL в поле `WebSocket URL`.
Не открывайте `http://127.0.0.1:8000/ws` напрямую в браузере: WebSocket-эндпоинт должен подключаться как `ws://127.0.0.1:8000/ws`.
