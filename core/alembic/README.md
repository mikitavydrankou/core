# Alembic Usage

This folder contains the migration tooling and history for the backend database.

## Layout

- env.py - Alembic runtime config, loads app models and DATABASE_URL.
- script.py.mako - Template for new migration files.
- versions/ - Migration history (one file per revision).

## Environment

Alembic reads DATABASE_URL from the environment. Example:

export DATABASE_URL=postgresql+asyncpg://postgres:secret@localhost:5432/taxi

## Common commands

Create a new migration from models:

python -m alembic revision --autogenerate -m "add_table"

Apply all migrations:

python -m alembic upgrade head

Rollback one step:

python -m alembic downgrade -1

Show current revision:

python -m alembic current

Show history:

python -m alembic history

## Makefile shortcuts

If you use Make, you can run:

make db-revision msg="add_table"
make db-upgrade
make db-downgrade
make db-current
make db-history

## Notes

- Always review autogenerated migrations before applying.
- Keep migrations small and focused.
- Do not edit the database manually in production; use migrations.
